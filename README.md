# meu-blog
Esse é o meu blog que eu fiz pra ajudar as pessoas, para organizar conteúdos, compartilhar um pouco dos meus recursos e indicar varias dicas de estudos.
O meu blog serve para compartilhar conhecimento e o objetivo do blog é ajudar as pessoas que tem dificuldades, e a importancia dos estudos.
No meu blog eu utilizei o index.html o script.js e o style.css.
Para o meu blog eu decidi fazer sobre estudos, porque nunca consegui aprender muito bem so na sala de aula com os professores explicando, entao fiz esse blog pensando nas pessoas que tambem nao sabem outra forma de começar a estudar, espero ter ajudado.
